# Security Policy

This repo is the configuration for one home's devices and Home Assistant. A
security issue here is either a flaw in the config anyone could reuse or a
live exposure of the actual home network.

## Reporting a vulnerability

**Please do not open a public issue for a security problem, and never post a
secret, credential or network detail anywhere in this repo, including an
issue, a commit message or a PR.**

Report it privately through GitHub: Security, then "Report a vulnerability"
(`https://github.com/mark-brannan/home-automation/security/advisories/new`).
Describe what you found and how to verify it, without the value of any live
credential.

A live credential leak is the urgent case: treat it as compromised and rotate
it before anything else.
